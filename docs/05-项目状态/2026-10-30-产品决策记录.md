## 4. 第四轮：交付方式

产品答复“都行看你”，按开发方建议执行。

| # | 决策 |
|---|---|
| 1 | 按 8 个 Phase 推进，先打通主链路，玩法后置（见 [Phase开发计划](<2026-10-30-Phase开发计划.md>)） |
| 2 | 原文需求全部进 V1；V1 不做项见 PRD §4 |
| 3 | 测试环境：现有服务器新开 `/sl/`；广告机在用的 `/mc/` 保持不动，Phase 8 再切换；Phase 3~6 在广告机实测 |
| 4 | 一个 Phase 一个 PR（`feature/bcxdawn222` → `dev`），产品审核合并；`dev` → `main` 只在验收发版时做 |
| 5 | 本轮结论追加到 PR #1，合并后开始 Phase 1 |
| 6 | 建“平台演示商家”，放 5 件测试服饰，上线前停用 |
| 7 | Phase 1 部署前，产品方更换服务器密码、重建 Xmax 永久密钥；新密钥只写服务器 env |
| 8 | 无硬性截止日期，按 Phase 估工期 |
| 9 | 开源复用不按许可证筛选，许可证只做记录（见 [开源复用清单](<../03-接口与集成/开源复用清单.md>)） |
