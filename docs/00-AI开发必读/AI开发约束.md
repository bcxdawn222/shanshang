# AI开发约束

> 文档用途：Claude Code、Codex 等 AI 与工程师的共同约束
> 当前状态：已完成
> 最后更新时间：2026-10-30

- 开发前先读 [PRD](<../01-项目需求/闪裳Live-PRD-V1.0.md>) 和 [产品决策记录](<../05-项目状态/2026-10-30-产品决策记录.md>)，按需求编号确认范围和验收标准。
- PRD 没写的规则不自行发明，先问产品；确实需要先做的，做成可配置项并登记到决策记录。
- 只在 `feature/*` 分支开发，经 PR 合入 `dev`；不直接提交 `dev` / `main`。
- 本仓库公开：禁止提交密钥（Xmax `uk-`、支付商户密钥）、服务器密码、服务器 IP、真实用户数据。全部走环境变量，仓库只放 `.env.example`。
- 不复刻、不调用原厂“幻衣魔镜”的接口、域名和服务器。原厂逆向资料只作背景参考，不进本仓库。
- 设备端是 Xmax 计费链路：任何会自动重连、自动开会话的逻辑都要有上限，防止空跑烧积分。
- 区分“代码实现 / 测试通过 / 部署 / 业务验收”四个状态，不混写。
- 不做人脸识别、不采集顾客身份信息（FUN-07）。
- 复用开源代码前查 [开源复用清单](<../03-接口与集成/开源复用清单.md>)；引入新来源时补登记，许可证只记录不筛选。
