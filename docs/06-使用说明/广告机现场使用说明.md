# 广告机现场使用说明

> 文档用途：广告机安装绑定、顾客操作与现场排障
> 当前状态：待验证（按 2026-10-31 代码编写；摄像头试穿、扫码、竖屏排版尚未真机验证）
> 最后更新时间：2026-10-31

本文写给门店店员和安装维护人员。不需要懂技术，按步骤操作即可。

## 1. 安装前准备

- 广告机能上网。
- 摄像头已接好，朝向顾客站立的位置。
- 广告机外壳（或浏览器）打开「平台提供的设备前台地址」。地址找平台管理员要。
- 地址必须是 https 开头。否则摄像头可能打不开，待机广告也存不到本机，断网后放不出来。

## 2. 首次开机与绑定

1. 打开设备前台地址。屏幕先显示“正在连接…”。
2. 连上后，屏幕显示“设备尚未绑定”，中间是一串 8 位设备码（字母加数字）。
3. 把这 8 位码拍照或抄下来，发给平台管理员。同时告诉管理员这台机器的名称和摆放地点。
4. 管理员在总后台“设备管理 → 绑定设备”录入设备码。
5. 不用动广告机。录入后约 5 秒内，屏幕自动进入首页。

注意：

- 设备码只有大写字母和数字，管理员录入时大小写都可以。码里不会出现 0、O、1、I、L 这类容易看错的字符。
- 绑定前不能试穿。

### 2.1 什么时候要重新绑定

| 情况 | 屏幕表现 | 怎么处理 |
|---|---|---|
| 管理员把设备停用 | 停用后最长约 1 分钟，屏幕显示“设备已停用”和设备码 | 联系管理员在总后台点“启用”。启用后约 5 秒自动回到首页，不用重新绑定 |
| 设备凭证失效（例如平台数据被重置） | 自动换成一个新的 8 位设备码，显示“设备尚未绑定” | 把新码发给管理员重新绑定 |
| 清了浏览器缓存、重装外壳、换了浏览器 | 同上，出现新设备码 | 同上。旧设备码在后台会留成一条离线记录，请管理员停用旧记录 |

设备码会一直存在这台机器上。不清缓存的话，重启、断电后还是原来的码，不需要再绑。

## 3. 首页 10 个入口

首页提示“选择一个分类，开始实时试穿”。10 个入口如下：

| 入口 | 是什么 |
|---|---|
| 流行男装 | 男装分类选衣 |
| 流行女装 | 女装分类选衣 |
| 童装 | 童装分类选衣 |
| 热门榜 | 近 7 天试穿最多的服饰，最多 20 件 |
| 宴会时装 | 带“宴会”场景标签的服饰，点开直接选衣 |
| 热播短剧同款 | 管理员整理的短剧专题，选剧再选同款 |
| 运势穿搭 | 选生日，看今日运势和幸运色穿搭 |
| 星座轮盘 | 选星座，转轮盘，看今日幸运色或风格 |
| AI智趣推荐 | 回答三个问题，推荐搭配 |
| 广告短剧热门 | 直接进入广告播放 |

二级页面左上角是“‹ 返回”，右上角是“返回首页”。

## 4. 顾客怎么试穿

### 4.1 选衣服

以男装为例：

1. 点“流行男装”。
2. 选“当季热卖套装”或“上装单品”。每项后面显示有几件。
3. 选品牌。
4. 选品类（如 T恤、外套）。
5. 点一件服饰，进入试穿。

女装、童装同样操作。

### 4.2 试穿画面

- 进入后提示“正在连接试穿服务，请站到镜头前…”。顾客站到镜头前，稍等几秒，画面里的衣服就会换成选中的款式。
- 底部服饰条：同一列表的其他衣服。点一下即可换装，不用重新连接。换装时提示“正在换装，请稍候”。换装失败会提示“换装失败，已保留上一件”。
- 角标“店铺位置”：显示这件衣服所在店铺位置；有优惠时下面显示优惠文字。角标里还有“扫码领优惠”按钮。
- “结束试穿”按钮：结束并回到上一页的服饰列表。

### 4.3 试穿时长上限

- 单次试穿默认最多 5 分钟（总后台可改）。从进入试穿画面开始算，连接的时间也算在内。
- 到时全屏提示“已试穿 X 分钟，点击继续”。
- 点屏幕任意位置即可继续，再计一轮。
- 15 秒没人点，自动结束试穿，回到首页。
- 试穿画面在屏时不会进入待机播放，顾客只站在镜头前不碰屏幕也没关系，到上限时由“点击继续”提示来结束。

### 4.4 扫码领优惠

1. 试穿画面出来后，点角标里的“扫码领优惠”。画面没出来时按钮不能点。
2. 屏幕提示“扫码将保存您的试穿照片”。顾客点“确认”，或点“取消”放弃。
3. 确认后，设备保存当时的试穿画面，并在下方加上店铺、商品名、优惠和核销码。按钮显示“生成中…”。
4. 屏幕弹出二维码和 6 位核销码。顾客用微信扫码，可以打开并长按保存照片。
5. 二维码 30 秒后自动关闭，也可以点“关闭”。
6. 顾客 7 天内到店出示核销码。店员在商家后台输入这 6 位码，或用已登录商家账号的手机扫码后点“确认核销”。

说明：

- 核销码只能用一次，只能由这件衣服所属的商家核销。
- 领取期间试穿不中断。
- 失败时只弹提示，不会自动重试。按提示稍后再点即可。

## 5. 互动玩法

### 5.1 星座轮盘

1. 选自己的星座（12 个）。
2. 选“女士 / 男士 / 童装”。
3. 点“转动轮盘”，或用手指甩一下转盘。
4. 转盘停下后显示“星座 · 幸运色或风格”，下面推荐几件匹配的服饰（最多 6 件）。
5. 点服饰进入试穿。点“再转一次”可以重新转。

### 5.2 运势穿搭

1. 选生日月份。
2. 选日期。
3. 选“女士 / 男士 / 童装”。
4. 显示今日运势卡：综合、桃花、事业三项星级，一句运势，今日幸运色，以及 3 件幸运色穿搭。
5. 点服饰进入试穿。

同一个生日同一天，结果相同。

### 5.3 AI智趣推荐

1. 选“女士 / 男士 / 童装”。
2. 选场合（如约会局、面试、通勤，选项由总后台配置）。
3. 选想要的感觉（如温柔、酷飒）。
4. 推荐 6 件服饰，点击试穿。点“换一批”看别的。
5. 同一位顾客连续使用期间，同一组问题不会重复推同一件。推完会提示“已经为你推荐完全部搭配”，然后重新挑。

这是按标签规则推荐，不识别顾客。

### 5.4 热门榜、短剧同款、广告短剧热门

- 热门榜：按近 7 天试穿次数排名，前 3 名标亮。每件显示名次和试穿次数。点击试穿。
- 热播短剧同款：先选一部剧，再看同款服饰，点击试穿。没有专题时显示“暂无内容”。
- 广告短剧热门：直接进入广告播放。碰一下屏幕回首页。

## 6. 待机播放

- 默认 4 分钟没人碰屏幕，自动进入广告播放（总后台可改）。
- 试穿中不计入待机。试穿由时长上限（默认 5 分钟“点击继续”，15 秒无人点自动结束）收尾，结束后回到首页，之后无人操作再按上面的时间进入播放。
- 广告是视频和图片轮流播，内容由总后台投放。
- 没有广告时，显示平台 Logo、名称和“触摸屏幕，开始实时试穿”。
- 碰一下屏幕，立即回到首页。
- 断网时继续播已经存到本机的广告。前提是设备前台地址是 https 开头；不是的话广告存不到本机，断网后放不出来，只显示 Logo 待机画面。
- 后台改了广告，约 5 分钟内自动更新，不用重启。试穿进行中不下载新广告。

## 7. 隐私说明

顾客问起时可以这样回答：

- 不做人脸识别，不采集顾客身份，不需要注册登录。
- 摄像头画面只用来实时换装。
- 运势穿搭里选的生日不保存、不上传。
- 只有顾客主动点“扫码领优惠”并确认，才保存一张试穿照片。
- 照片只能通过二维码里的链接打开，别人猜不到链接。照片 7 天后自动删除。

## 8. 计费提示（店员了解即可）

- 顾客试穿某件衣服时，按这件衣服实际在屏幕上的时间，按秒扣这件衣服所属商家的积分。
- 一次试穿换了几家的衣服，各家分别扣。
- 画面还没出来、连接中、断线时不计时。结束试穿、自动结束、进入待机时停止计时。
- 商家积分低于提醒线（默认 5 积分）时，这家的衣服会自动从广告机上消失。充值后会重新出现。
- 正在试穿时积分用完，不会打断顾客。

## 9. 常见问题

### 9.1 屏幕一直显示设备码

- 还没绑定。把屏幕上的 8 位码发给平台管理员，请他在总后台绑定。
- 管理员说已经绑了，但屏幕没变：核对码是否一致。清过缓存的机器会换新码，要按屏幕上当前的码绑。
- 显示“网络异常，正在重新连接…”：检查广告机网络，设备每 15 秒自动重试。

### 9.2 摄像头打不开

- 提示“摄像头没有权限，请联系工作人员”：在外壳或浏览器里允许这个地址使用摄像头，然后点“重新试穿”。
- 提示“没有找到摄像头，请联系工作人员”：检查摄像头线是否插好，换个接口试试，再点“重新试穿”。
- 设备前台地址不是 https 时，浏览器可能不给摄像头权限。请联系平台管理员。

### 9.3 试穿连接失败

- 网络中断时，设备会自动重连 2 次（先等 3 秒，再等 10 秒），屏幕显示重连进度。
- 2 次都失败后，不再自动重连，屏幕显示原因和“重新试穿”“返回”两个按钮。需要人工点“重新试穿”。
- 摄像头、密钥、额度这类问题不会自动重连，直接显示原因。
- 提示“试穿服务额度不足，请联系工作人员”：联系平台管理员。
- 广告机切到后台或熄屏时，试穿会自动结束，这是正常的。

### 9.4 某些服饰不显示

可能原因：

- 商家积分低于提醒线，衣服被自动隐藏。请商家充值。
- 衣服还在审核期，或已下架，或商家被停用。
- 没有衣服的品牌、品类不会出现在选项里。“当季热卖套装 / 上装单品”两项总会显示，没有衣服时显示“0 件”，点进去为空。
- 后台刚改过，设备约 1 分钟后才更新列表。返回上一层再进来即可。

### 9.5 背景是黑色还是白色

由平台管理员在总后台“设备管理 → 编辑设备”里按设备设置。改完后约 30 秒内自动切换，不用重启。

### 9.6 画面卡在待机

- 先碰一下屏幕，正常会立即回到首页。
- 某条广告加载不出来时，设备会自动跳过（最多等 20 秒）。
- 一直只显示 Logo：说明没有可播的广告，或广告还没下载完。碰屏幕可正常使用。请管理员检查投放。
- 碰屏幕没有反应：重启广告机外壳或刷新页面。不要清浏览器缓存，否则要重新绑定。
