## 1. 环境

| 环境 | 位置 | 说明 |
|---|---|---|
| 开发测试 | 现有共用服务器，新增 nginx `location /sl/` | 只新增 location，不改他人站点和 server 块；广告机在用的 `/mc/` 不动 |
| 生产 | 独立服务器（2C4G 起）+ 备案域名 + HTTPS | Phase 8 上线；之后广告机外壳切到新地址，旧 `/mc/` 下线 |

**Phase 1 部署前置**：产品方更换现有服务器密码、在 Xmax 平台重建永久密钥；新密钥只写服务器 env 文件。

## 2. 目标拓扑

```
nginx（生产 HTTPS）
├── <前缀>/admin/   总后台 + 分后台（同一 SPA）
├── <前缀>/device/  设备前台
├── <前缀>/s/       快照页（服务端直出）
└── <前缀>/api/     Node 服务（127.0.0.1 本机端口）
                     └── SQLite（单文件，WAL）+ 本地 media/
```

开发期 `<前缀>` = `/sl`，生产为空。

## 3. 环境变量

| 变量 | 说明 |
|---|---|
| `HOST` / `PORT` | 服务监听地址与端口（默认 `127.0.0.1:8300`） |
| `DATA_DIR` / `DB_FILE` | SQLite 与媒体目录 |
| `TRUST_PROXY` / `COOKIE_SECURE` | nginx 反代后设为 `1`（只认 `1`） |
| `SESSION_TTL_HOURS` | 登录会话有效期 |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | 首次启动初始化超级管理员 |
| `XMAX_API_KEY` / `XMAX_API_BASE` | Xmax 永久密钥与地址 |
| `XMAX_KEY_EXPIRE_SECONDS` / `XMAX_KEY_POINTS_LIMIT` | 设备临时密钥有效期与额度 |
| `PUBLIC_BASE_URL` | 快照二维码使用的外网地址（Phase 5 加入） |

路由前缀 `/sl` 由 nginx 反代时去掉，服务端不需要配置；会话令牌只存哈希，不需要签名密钥。提供 `.env.example`，真实 `.env` 不入库（已在 `.gitignore`）。具体步骤见 [部署手册](<部署手册.md>)。

## 4. 发布与回滚

- 发布：构建产物 + 服务端代码打包，带版本号；发布前备份 SQLite 文件。
- 回滚：切回上一版本目录 + 恢复数据库备份。
- systemd 管理，独立低权限用户运行。
