# 服务器与部署

> 文档用途：部署拓扑、环境变量、发布与回滚
> 当前状态：未完成（服务器选型待确认 Q8；域名待确认 Q7）
> 最后更新时间：2026-10-30

本仓库公开：服务器地址、账号、密码、密钥不写入本文，存放在私有渠道。

## 1. 现状

- 现有单机试穿后端部署在一台与他人共用的小规格云服务器上（2C/1.8G，无数据库），通过 nginx 子路径挂载。
- 该机器上有他人站点，**不得改动其 nginx server 块和其他服务**，只能新增 location。

## 2. 目标拓扑（待 Q8 确认）

```
nginx (HTTPS, 备案域名)
├── /admin/   管理端 + 商家端前端（同一 SPA，按角色路由）
├── /device/  设备前台
├── /s/       快照页（微信扫码落地）
└── /api/     Node 服务（127.0.0.1 本机端口）
                └── SQLite（单文件，WAL）+ 本地 uploads/
```

## 3. 环境变量

| 变量 | 说明 |
|---|---|
| `PORT` | 服务监听端口 |
| `DATA_DIR` | SQLite 与上传文件目录 |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | 首次启动初始化管理员 |
| `SESSION_SECRET` | 会话签名 |
| `XMAX_API_KEY` / `XMAX_API_BASE` | Xmax 永久密钥与地址 |
| `PUBLIC_BASE_URL` | 快照二维码使用的外网地址 |

提供 `.env.example`，真实 `.env` 不入库（已在 `.gitignore`）。

## 4. 发布与回滚

- 发布：构建产物 + 服务端代码打包，带版本号；发布前备份 SQLite 文件。
- 回滚：切回上一版本目录 + 恢复数据库备份。
- systemd 管理，独立低权限用户运行。
