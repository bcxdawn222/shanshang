## 1. 产品定位与商业模式

闪裳Live 是广告机（55 寸触摸屏）实时 AI 试穿设备的运营系统。

- 设备归平台所有，摆在商场或门店，多个入驻商家共用。
- 商家把自家服饰上架到设备上；顾客试穿某商家服饰产生的费用，从该商家的平台积分里扣。
- 平台积分与 Xmax 积分分离，换算比例只有平台可见。

| 端 | 使用者 | 作用 |
|---|---|---|
| 总后台（管理端） | 平台超级管理员（V1 仅 1 个） | 最高权限：审核商家、格位、积分、上架审核、设备、内容运营、全局数据 |
| 分后台（客户端） | 入驻商家，一个账号 = 一个品牌 | 上架自家服饰、看自家数据、账号设置、核销 |
| 设备前台 | 门店顾客（不登录） | 分类选衣、实时试穿、扫码领优惠、待机广告、互动玩法 |

两个后台是同一套前端和接口，按角色区分菜单；总后台只多出调度监管和最高权限。

## 3. 非功能要求

- 设备前台运行在广告机双应用外壳内，替换外壳里现有的“我们的试穿”应用；外壳和“幻衣魔镜”不动。
- 公开仓库：密钥、服务器地址、口令不入库，全部环境变量注入。
- Xmax 永久密钥只在服务端；设备凭设备凭证换短期临时密钥。
- 不做人脸识别，不采集顾客身份信息；快照只凭随机令牌访问，7 天删除。

## 4. V1 不做

- 微信在线充值（V2，需要商户号和备案域名）。
- 商家付费推荐位、商家自投广告。
- 多个子管理员、分权限。
- 大模型版运势、推荐。
- 人脸识别、顾客注册登录；真实模型训练；复刻原厂“幻衣魔镜”接口。
