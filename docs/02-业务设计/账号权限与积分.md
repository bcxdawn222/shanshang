# 账号权限与积分

> 文档用途：账号模型、权限矩阵、积分账本规则
> 当前状态：待验证（依赖 Q1、Q3、Q9）
> 最后更新时间：2026-10-30
> 对应需求：ACC-*、SET-01~03、SET-05、ADM-01~04

## 1. 账号模型

| 角色 | 创建方式 | 登录 |
|---|---|---|
| `admin` 平台管理员 | 部署时由环境变量初始化，不开放注册 | 账号 + 登录口令 |
| `merchant` 商家 | 注册页自助注册（是否需管理员审核待确认，默认注册即可用） | 用户名 + 密码 |

- 密码：scrypt/bcrypt 加盐哈希；会话用 HttpOnly Cookie，改密后旧会话全部失效。
- 登录限流：同 IP + 同账号连续失败 5 次锁 15 分钟。

## 2. 权限矩阵

| 能力 | 商家 | 管理员 |
|---|---|---|
| 查看/修改自己昵称、密码 | ✅ | ✅ |
| 修改品牌名、Logo | ❌ | ✅ |
| 上传服饰（格位内） | ✅ | ✅（可代传） |
| 加格 | ❌ 提示联系管理员 | ✅ 每次 +5 |
| 服饰训练 / 审核上架 | ❌ 提示“你的账户没有权限，请联系管理员” | ✅ |
| 积分充值 | 待确认 Q3 | ✅ 手动调整 |
| 查看统计 | 仅自己 | 全部 |
| 账号启停、重置密码 | ❌ | ✅ |
| 视频/幻灯片素材 | ❌（待确认是否允许商家上传广告） | ✅ |

所有权限在服务端校验，前端隐藏按钮只是体验，不作为安全边界。商家接口一律带 `merchant_id = 当前登录者` 过滤。

## 3. 积分账本

- 只追加流水：`充值 / 管理员调整 / 试穿消耗 / 退回`，余额 = 流水求和，另存快照字段加速查询并定期对账。
- 试穿消耗口径待确认（Q3）。参考成本：Xmax 实测约 70 积分/分钟（平台侧成本，不等于对商家定价）。
- 余额不足时的行为待确认（默认：该商家服饰在设备上仍展示，但试穿时提示“暂不可用”）。

## 4. 账号使用总时长

默认口径：该商家服饰被试穿的会话时长累计（从出画面到结束试穿/切走）。待确认 Q9。
