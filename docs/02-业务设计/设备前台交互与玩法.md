# 设备前台交互与玩法

> 文档用途：设备前台导航结构、待机播放、互动玩法设计
> 当前状态：待验证（口径已确认，待开发）
> 最后更新时间：2026-10-30
> 对应需求：DEV-*、PLY-*、FUN-*

## 1. 导航结构

```
首页（10 个一级模块）
├── 流行男装 / 流行女装 / 童装
│   ├── 当季热卖套装 ─┐
│   └── 上装单品   ───┴→ 品牌（已审核商家）→ 品类 → 服饰 → 试穿
├── 热门榜            近 7 天试穿次数前 20，管理员可置顶/移出
├── 宴会时装          场景标签 = 宴会
├── 热播短剧同款      管理员专题（剧名、海报、同款服饰）
├── 运势穿搭          §4
├── 星座轮盘          §3
├── AI智趣推荐        §5
└── 广告短剧热门      直接进入播放页
```

- 试穿界面：全屏实时画面 + 底部服饰条 + 角标（店铺位置 +“扫码领优惠”）+ 结束试穿；避开外壳悬浮球所在角落。
- 全部交互用 `bindTap`（pointerdown + 同 pointerId 的 pointerup），按钮最小 64px，适配 55 寸竖屏。
- 设备背景黑/白由总后台按设备下发。

## 2. 试穿时长、待机与播放

- 单次试穿上限默认 5 分钟（可配）：到时弹“点击继续”，15 秒无人点则结束试穿。
- 任意指针事件重置空闲计时；4 分钟无操作进入播放页。试穿页在屏时不进待机：顾客站在镜头前不碰屏幕是常态，由上面的 5 分钟上限负责结束（`disconnect` 并上报离屏扣费）；试穿结束后重新开始 4 分钟计时（2026-10-31 调整 PLY-03）。
- 播放列表：视频与图片混排，按顺序循环，图片停留秒数可配，按设备投放。两个 `<video>/<img>` 元素交替淡入，约 200 行自写。
- 素材预缓存到本地（Cache Storage），断网继续播放已缓存内容。
- 触摸屏幕立即回到首页；离开待机即开启新的“设备会话”（FUN-07 用）。

## 3. 星座轮盘

1. 选 12 星座之一 → 选男/女/童。
2. 转盘 8~12 格，每格是该星座的一种幸运色或幸运风格（映射由管理员配置，预置默认值）。
3. 结果在启动前由种子随机确定，用 spin-wheel 的 `spinToItem()` 停到目标格；随机初速度 + `rotationResistance` 摩擦减速；支持手指甩动。
4. 指针拨片回弹 + “嗒嗒”声自写，挂在 `onCurrentIndexChange`；落定缓动用 `cubic-bezier(.3,.92,.2,1)`。
5. 停下后显示“白羊 · 热情红”，推荐 3~6 件主色或风格匹配的服饰，点击试穿。

## 4. 运势穿搭

- 输入：生日（月、日，不存储）+ 男/女/童；由生日推出星座（lunar-javascript）。
- 输出“今日运势卡”：综合、桃花、事业三项星级（1~5），一句运势文案，今日幸运色，3 件推荐服饰。
- 确定性：`rng = mulberry32(cyrb53(今天日期 + 月日 + 模块名))`，同一生日同一天结果相同。
- 文案库：“模板句 × 词槽”自建，签文素材（观音灵签、ssgw、诸葛神数）改写后入库；产品审核后上线。V1 不接大模型。

## 5. AI智趣推荐

- 三问：性别 → 场合（约会局、闺蜜局、见家长、面试、生日派对、旅行拍照、通勤、运动）→ 感觉（温柔、酷飒、高级、元气、松弛）。选项由管理员增删，每个选项映射到场景/风格/主色权重。
- 算法：
  1. 按性别过滤 READY 服饰，按标签匹配打分；
  2. 加入种子随机扰动；
  3. MMR 多样性重排（λ≈0.7，同商家、同品类、同主色视为相似）；
  4. 按商家分桶轮流取，保证结果分散到不同商家；
  5. 会话内记录“问题 → 已推荐服饰”，同一问题再问时排除；候选耗尽提示“已经为你推荐完全部搭配”并重置。
- “同一个人” = 同一设备一次连续使用（离开待机到再次待机），不做人脸识别。
- 每次推荐上报 `ai_recommend`，计入被推荐服饰所属商家。
- 页面称“AI 智趣推荐”，实现为规则算法。
