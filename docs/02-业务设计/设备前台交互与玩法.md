# 设备前台交互与玩法

> 文档用途：设备前台导航结构、待机广告、互动玩法设计
> 当前状态：待验证（运势穿搭玩法、Q4、Q11 待产品确认）
> 最后更新时间：2026-10-30
> 对应需求：DEV-*

## 1. 导航结构

```
首页（10 个一级模块）
├── 流行男装 / 流行女装 / 童装
│   ├── 当季热卖套装 ─┐
│   └── 上装单品   ───┴→ 品牌列表 → 品类（连衣裙/T恤/衬衫/外套/风衣/针织衫/西装/羽绒服）→ 服饰 → 试穿
├── 热门榜            按试穿次数排名
├── 宴会时装          按标签筛选
├── 热播短剧同款      按标签筛选
├── 运势穿搭          见 §4
├── 星座轮盘          见 §3
├── AI智趣推荐        见 §5
└── 广告短剧热门      进入视频/幻灯片播放
```

- 宴会时装、热播短剧同款用服饰“标签”实现，商家上传时可勾选。
- 试穿界面：全屏实时画面 + 底部服饰条 + 右下角店铺位置与二维码 + 结束试穿。避开广告机外壳悬浮球所在角落。
- 全部交互用 pointer 事件，按钮最小 64px，适配 55 寸竖屏。

## 2. 待机与广告

- 任意触摸/指针事件重置计时；4 分钟无操作进入播放页。
- 试穿进行中：默认不进入待机，但若 4 分钟无操作，先结束试穿（停止扣费）再进入播放（Q11）。
- 播放列表：后台配置的视频与图片混排，按顺序循环；图片默认停留 8 秒。
- “不同播放器轮流播放”理解为：多个视频源按列表轮播（待确认 Q12）。
- 视频预缓存到设备本地，断网时继续播放已缓存内容。
- 触摸屏幕立即回到首页。

## 3. 星座轮盘

1. 选 12 星座之一 → 选男/女/童。
2. 转盘扇区 = 从该性别 READY 服饰中按星座配色/风格标签抽取 8~12 件。
3. 动画：初速度随机，按摩擦系数指数衰减（`ω(t) = ω0·e^(-kt)`），末段加轻微回弹与指针“嗒嗒”拨片效果；结果在启动前已确定，动画反推初速度使其自然停在目标扇区。
4. 停下后进入该服饰试穿。

## 4. 运势穿搭（开发方方案，待产品确认）

- 输入：出生日期（只取月日，不存储）或直接选星座 + 性别。
- 输出：“今日幸运色 / 幸运风格 / 一句运势文案” + 推荐 3 件匹配幸运色或风格的服饰。
- 幸运色与文案按 `日期 + 星座` 确定性生成，同一天同一星座结果一致，有“每日运势”的真实感。
- 文案库本地维护，不依赖大模型；后续如需大模型生成，单列需求。

## 5. AI智趣推荐

- 输入：性别 + 场景（约会局、闺蜜局、面试局、聚会局、通勤局……，后台可配）。
- 算法：场景 → 标签权重，对候选服饰打分，按分数加权随机抽取 3 件。
- “同一人同一问题不出现同一套衣服”：
  - 默认“同一人” = 同一设备上一次连续使用会话（从离开待机到再次待机）。
  - 会话内记录已推荐服饰 ID，同一问题再次请求时排除；候选耗尽时提示“已经为你推荐完全部搭配”并重置。
  - 跨顾客不做识别，不采集人脸（Q4）。
- 每次推荐计入被推荐服饰的“AI 推荐次数”。

## 6. 黑白背景

商家设置的黑/白背景作用于该商家绑定的设备（若设备不绑商家，则由管理端统一设置，Q2）。
