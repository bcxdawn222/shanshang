# 数据统计埋点

> 文档用途：埋点事件定义与统计口径
> 当前状态：待验证
> 最后更新时间：2026-10-30
> 对应需求：STA-*、DEV-14

## 1. 事件

设备前台批量上报（每 10 秒或满 50 条），断网时本地缓存后补报。

| 事件 | 触发 | 关键字段 |
|---|---|---|
| `brand_click` | 点击品牌 | device_id, merchant_id, brand |
| `brand_dwell` | 离开品牌页 | 同上 + duration_ms |
| `tryon_start` | 试穿出画面 | garment_id, merchant_id, session_id |
| `tryon_end` | 结束/切换/待机 | 同上 + duration_ms |
| `ai_recommend` | AI 推荐展示 | garment_ids[], scene |
| `snapshot_create` | 生成二维码快照 | snapshot_id, garment_id |
| `snapshot_scan` | 快照页被打开 | snapshot_id |
| `redeem` | 店员核销（服务端产生） | snapshot_id, merchant_id |

## 2. 口径

| 指标 | 口径 |
|---|---|
| 品牌点击次数 | `brand_click` 计数 |
| 停留时长 | `brand_dwell.duration_ms` 求和，单次上限 10 分钟防挂机 |
| 商品试穿次数 | `tryon_start` 计数；同一会话同一服饰 30 秒内重复不重计 |
| 扫码核销件数 | `redeem` 计数 |
| 被 AI 推荐次数 | `ai_recommend` 中出现次数 |
| 热门榜 | 近 7 天试穿次数排序 |

明细表按日汇总到 `stat_daily`，后台查询读汇总表。
