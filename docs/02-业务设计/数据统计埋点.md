# 数据统计埋点

> 文档用途：埋点事件定义与统计口径
> 当前状态：待验证（口径已确认，待开发）
> 最后更新时间：2026-10-30
> 对应需求：STA-*、DEV-06、PT-02、SET-03

## 1. 事件

设备前台批量上报（每 10 秒或满 50 条），断网时本地缓存后补报；每条带 `device_id、session_id、seq`，服务端按 `device_id + session_id + seq` 去重。

| 事件 | 触发 | 关键字段 |
|---|---|---|
| `brand_click` | 点击品牌 | merchant_id |
| `brand_dwell` | 离开品牌页 | merchant_id, duration_ms |
| `tryon_start` | 某件服饰出画面 | garment_id, merchant_id |
| `tryon_end` | 该服饰离屏（切换/结束/待机/上限） | garment_id, merchant_id, duration_ms（同时触发扣费） |
| `ai_recommend` | AI 推荐展示 | garment_ids[], question_key |
| `snapshot_create` | 生成二维码快照 | snapshot_id, garment_id |
| `snapshot_scan` | 快照页被打开（服务端产生） | snapshot_id |
| `redeem` | 核销成功（服务端产生） | snapshot_id, merchant_id |

## 2. 口径

| 指标 | 口径 |
|---|---|
| 品牌点击次数 | `brand_click` 计数 |
| 品牌停留时长 | `brand_dwell.duration_ms` 求和，单次上限 10 分钟 |
| 服饰试穿次数 | `tryon_start` 计数；同一会话同一服饰 30 秒内重复不重计 |
| 服饰试穿时长 | `tryon_end.duration_ms` 求和，与扣费、账号使用总时长同口径 |
| 扫码核销件数 | `redeem` 计数 |
| 被 AI 推荐次数 | `ai_recommend.garment_ids` 中出现次数 |
| 热门榜 | 近 7 天试穿次数排序前 20，叠加管理员置顶/移出 |

明细按日汇总到 `stat_daily`（日期 × 商家 × 服饰 × 设备），后台图表和导出 Excel 读汇总表。
